# 人工课程性质清单

当前新增性质：**计算机限选**。`course_nature_overrides.json` 当前为空，未给任何课程推定标注。

## 后续表格推荐列

- **课程号**：推荐必填，使用文本格式，保留前导零（不要用 Excel 数值格式）。
- **课程名称**：推荐提供，用于人工核对；没有课程号时仅允许唯一、完全一致的名称匹配。
- **课程性质**：填写 `计算机限选`（若整张表都是这一类，可在交付时统一说明）。
- 可选：开课学院、适用年级、适用专业、方向、学期、来源/备注。如果只适用于某专业/年级，请务必注明，不能作为全局性质直接导入。

收到表格后先核对、去重并报告缺失或同名冲突，再填写 JSON；本次没有写入课程清单。

## JSON 契约

```json
{
  "version": 1,
  "byCourseId": {},
  "byCourseName": {}
}
```

`byCourseId` 的键是原始课程号，值为性质数组，例如某个**已确认**课程对应 `["计算机限选"]`；`byCourseName` 同理。这里不列虚构课程示例，防止误导入。课程号优先；同名多课程、未找到课程、未知性质或错误格式均拒绝构建，绝不模糊匹配或生成新课。

运行 `python3 build_data.py` 后，附加性质写入 master/public 的 `tags` 和可选 `extraNatureTags`。课程搜索、预选和正选/补退选筛选与标签展示自动消费这些字段。空映射不改变任何课程数据。修改后须提交映射和构建产物，再部署。

附加性质不覆盖 `plans[].nature`，也不改变培养方案或毕业学分统计；因此全局人工标签切换培养方案后仍保留。若学校培养方案原生出现 `计算机限选`，按普通性质解析并遵循方案范围。**计算机限选不自动等同“专业限选”硬性学分要求**，相关统计规则待正式表格/要求确认。
